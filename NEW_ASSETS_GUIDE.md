## How to Add Audio to the Project

### For Music Tracks:
1. Download MP3 from Pixabay/Incompetech
2. Place in `public/assets/audio/music/`
3. Name as: `music-{genre}-{number}.mp3` (e.g., `music-phonk-01.mp3`)
4. Add entry to `manifest.json` under `audio.music`

### For Sound Effects:
1. Download from Freesound/Zapsplat
2. Place in appropriate folder:
   - Reactions: `public/assets/audio/sfx/reactions/`
   - Animals: `public/assets/audio/sfx/animals/`
   - Silly: `public/assets/audio/sfx/silly/`
3. Name as: `sfx-{category}-{name}.mp3`
4. Add entry to `manifest.json`

### For Voices:
1. Generate with TTS tool
2. Place in `public/assets/audio/voices/`
3. Name as: `voice-{phrase}.mp3`
4. Add entry to `manifest.json`

## Manifest Update Required

After creating/downloading new assets, update `public/assets/manifest.json`:

```json
{
  "id": "your-asset-id",
  "name": "Display Name",
  "file": "path/to/file.ext",
  "category": "appropriate-category",
  "tags": ["relevant", "tags"],
  "ageAppropriate": true,
  "license": "CC0",
  "source": "Source Name"
}
```

## ⚠️ Important Note About Audio Files

The current placeholder audio files were created as WAV files with .mp3 extensions. **These will not play in browsers**.

The app now handles this gracefully by:
- Detecting failed audio loads
- Using a working silent MP3 placeholder for playback timing
- Allowing the audio mixer to function (play/pause/timeline work)
- Showing console warnings when placeholder audio is used

**To add real audio:**
1. Download MP3 files from the free sources listed above
2. Replace the placeholder files in `public/assets/audio/`
3. Keep the same filenames as listed in manifest.json
4. Refresh your browser to clear the cache
